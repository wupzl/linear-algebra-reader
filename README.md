# 数学帝国：线性代数编年史

十一章入门阅读，涵盖向量、矩阵、行列式、消元、向量空间、特征值、最小二乘、SVD 和矩阵几何。包含二维交互图、每章两道自评练习、字号和主题切换。进度保存在当前浏览器。

- [打开阅读器](https://wupzl.github.io/linear-algebra-reader/)
- 正文和练习源文件为 book.txt，chapters/ 提供逐章 Markdown。
- 安装 Python Markdown 后运行 python build.py，重新生成章节和目录。公式使用 MathJax。
- GitHub Pages 从 main 分支的 /docs 发布。
